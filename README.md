# 🇲🇽 Spanish A1 — Daily Practice

**Learn Spanish one word, one sentence, and one lesson at a time.**

Spanish A1 — Daily Practice is a free, interactive learning application designed for beginners who want to develop practical Spanish conversation skills.

The application features 38 beginner lessons covering 187 essential Spanish words and expressions, interactive vocabulary quizzes, sentence translation exercises, pronunciation assistance, and progress tracking.

Learners can study at their own pace, practice everyday Latin American Spanish, and test their knowledge with an A1 Graduation Test that unlocks introductory A2 lessons.

Built entirely with HTML, CSS, and JavaScript, the application requires no registration, subscription, or database.

**Simple lessons. Practical Spanish. Learn anywhere.**
